## Current research

**VLM-DP3 manipulation for static-to-dynamic OOD generalization** - semester thesis, ongoing

Investigating whether VLM task-stage reasoning and scene/object semantic grounding can improve the transfer of DP3 3D visuomotor policies from static demonstrations to dynamic real-robot deployment. My work covers teleoperated data collection, RGB-D point-cloud observations, data validation, policy training/evaluation, and closed-loop deployment on a Franka manipulator.
